Fast API - Python

What is FastAPI?
   FastAPI is a modern Python web framework used to build APIs quickly

REST API - standard for APIs (web services) dev 

Python : Django, Flask

Python has asyncio
NodeJS has libuv -> event loop

Starlette uvloop sits on libuv

FastAPI : starlette (web development framework), pydantic (data validation and serialization) 
    -ASGI (Asynchronous server gateway interface) based web dev framework 

uvicorn runs the FastAPI (starlette) app
